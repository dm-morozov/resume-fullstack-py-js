# Расчёт подневных товарных остатков

## Принятые решения

В результирующие файлы включаются все пары `item_id/location_id`,
в том числе позиции с нулевым остатком, поскольку условие задания
не требует исключать их из результата.

Для расчёта количества и себестоимости используется `Decimal`,
что исключает накопление погрешности при сложении денежных значений.

## Запуск

Требуется Python 3.9 или новее. Сторонние зависимости не используются.

python stock.py

Скрипт читает начальный остаток из каталога stock, помесячные движения
из каталога invent_trans и формирует подневные остатки в каталоге stock.
