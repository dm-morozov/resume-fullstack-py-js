# Расчёт подневных товарных остатков

Скрипт рассчитывает остатки товаров на конец каждого дня на основании
начальных остатков и помесячных CSV-файлов товарных движений.
Исходное условие приведено в [description_task.md](description_task.md).

## Алгоритм

1. Загрузить начальные остатки на 30.04.2025.
2. Сгруппировать движения по дате, товару и подразделению.
3. Последовательно применить операции за каждый день расчётного периода.
4. Записать остатки в подневные файлы `stock_YYYY_MM_DD.csv`.

## Принятые решения

- Для расчёта количества и себестоимости используется `Decimal`,
  чтобы избежать накопления погрешности при сложении десятичных значений.
- В результат включаются все пары `item_id/location_id`, в том числе позиции
  с нулевым остатком, поскольку условие не требует исключать их.
- Строки результата сортируются по `item_id` и `location_id`
  для детерминированного порядка записей.
- Для ключевых этапов загрузки и записи ведётся журнал выполнения.

## Структура данных

```text
invent_trans/
├── invent_trans_2025_05.csv
├── invent_trans_2025_06.csv
└── invent_trans_2025_07.csv
stock/
└── stock_2025_04_30.csv
```

## Запуск

Требуется Python 3.9 или новее. Сторонние зависимости не используются.
Запускать скрипт нужно из каталога с файлом `stock.py`:

```bash
python stock.py
```

Результаты записываются в каталог `stock` с именами
`stock_YYYY_MM_DD.csv`. Существующие файлы с такими именами перезаписываются.
